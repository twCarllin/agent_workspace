# 影響分析

## 觸發與載入

主 flow 提出具名影響問題時，可派 impact-analyzer；角色依 `.agent-flow/roles/impact-analyzer.md` 載入本 skill。輸入包括問題原文、Spec、變更範圍及已知證據位置。缺少問題或 Spec 時停止並回報。依問題範圍重用仍有效的調查結果，補查證據缺口。

## 方法

1. 從被改介面及資料產生處追查引用、呼叫端與資料流。涵蓋跨模組、跨程序及持久化邊界，記錄傳遞媒介、資料格式與實際消費端位置；不得只依直接呼叫推定影響。從 repository 根目錄搜尋相關名稱及別名，記錄查詢方式和結果。
2. 列出問題涉及的影響與各消費端，附檔案行號或其他可重查證據。宣稱沒有呼叫端前，記錄搜尋範圍、查詢及零命中結果；無法確認時標示未知。
3. 找出影響判斷依賴的關鍵安全前提，依實際程式及可觀察結果驗證，記錄前提、驗證條件、命令或操作、結果及證據位置。無法實證時標示未知及缺少的證據，不假定前提成立。

## 權限、停止與輸出

依角色的既有權限將答案寫入 Spec；其他調查只讀取、搜尋、查詢歷史及執行不修改狀態的命令，不修改其他檔案或外部狀態。問題已回答且證據足夠時停止，交付精簡影響摘要與證據位置。無法取得必要證據時停止，回報未知、已查範圍及缺口。
