  - 行為：stdin 收 PostToolUse JSON。`tool_name` 為 Task／Agent 且 `subagent_type` 在信封名單（7 類：code-writer、code-reviewer、task-verifier、retro、impact-analyzer、usage-analyzer、task-decomposer）時，對 subagent 最終文字驗：①首行為戳記行 `* _YYYY-MM-DD HH:MM (<model>)_`；②恰一個 `Self-check:` 行且為最末非空行；③`subagent_type` 為 task-verifier 時文內須含「完成度」與「憑據」。任一不成立 → exit 2，stderr 輸出標準化退件訊息（列缺項＋「退件重取」指示）。解析異常（stdin 非 JSON、欄位缺席、回覆非文字）一律 exit 0（fail-open——本 hook 是品質 lint，不是安全 gate）。
  - DoD：
    1. script 依上述行為實作，含檔頭用途註解與信封名單常數。
    2. 契約表 8 row 各有測試斷言（黑箱：subprocess 餵 stdin、驗 exit code 與 stderr）。
    3. 全套測試無新增失敗。
  - 契約：
    | # | 輸入 | 預期 |
    |---|------|------|
    | 1 | Agent＋task-verifier＋合規報告（戳記＋末行 Self-check＋含完成度/憑據） | exit 0，無輸出 |
