### Item 2：新增 token_usage.py 量測腳本
- **files**: `.claude/hooks/token_usage.py`（新）、`tests/test_token_usage.py`（新）
- **做什麼**: CLI `python3 .claude/hooks/token_usage.py <run_id> [--dir run] [--full-session] [--write] [--projects-root <dir>]`。
  - **定位 transcript**：manifest 有 `session_id`／`config_dir` → 主 flow 檔＝`<config_dir>/projects/<cwd 編碼>/<session_id>.jsonl`，subagent 檔＝同層 `<session_id>/subagents/agent-*.jsonl`，各配 `.meta.json`（鍵 `agentType`、`description`）。cwd 編碼＝`re.sub(r"[^A-Za-z0-9]", "-", os.getcwd())`。`--projects-root` 給定時直接以該目錄為 `projects/<cwd 編碼>/` 的替代（測試注入用，免動 HOME）。
  - **舊 run fallback**：manifest 無 `session_id` → glob `~/.claude*/projects/*/*.jsonl`（不含 subagents 子目錄），挑檔內含 run_id 字串者，逐檔照同法加總；候選檔 0 個 → stderr 訊息、exit 1。
  - **時間窗**：讀 `run/<run_id>.events.jsonl` 全部行的 `ts` 取 min／max 為 [lo, hi]；transcript 每行 `type == "assistant"` 且 `timestamp` 落在窗內者計入（時間戳統一以 `datetime.fromisoformat(s.replace("Z", "+00:00"))` 比較）。`--full-session` 或 events 檔不存在 → 不切窗、整檔計入。
  - **加總**：`message.usage` 的 `input_tokens`／`cache_creation_input_tokens`／`cache_read_input_tokens`／`output_tokens`（缺鍵視 0）＋ `turns`（訊息數）。壞 JSON 行寬容跳過（比照 `stats.py._parse_events`）。
  - **分類**：subagent `agentType` ∈ {`usage-analyzer`, `task-decomposer`, `impact-analyzer`} → prep；其餘（含缺 meta）→ loop。
  - **輸出（stdout）**：主 flow 一行、每個 subagent 一行（agentType＋description 前 30 字＋四欄＋turns）、合計一行；`total`＝四欄相加。
  - **`--write`**：回寫 manifest `subagent_usage = {"prep": int, "loop": int, "main": int}`（各為所屬檔四欄加總）與 `token_usage = {"session_id", "window": [lo, hi] 或 null, "main": {四欄＋turns}, "subagents": [{"agent_type", "description", 四欄＋turns}]}`；其他欄位不動。無 `--write` 不寫任何檔。
  - 重用：manifest 判定用 `eval_gates.MANIFEST_RE`（不自建 pattern）；壞 JSON 讀法比照 `stats.py.load`。
