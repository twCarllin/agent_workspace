# RETRO

> 每條寫成可直接貼進 writer prompt 的**約束句式**（背景一句、約束一句），不寫敘事——retro 的消費方式是前置進 prompt 硬性約束區（eval-flow 循環 step 1），不是開工前通讀。
>
> **ID 規則**：每條依檔內順序編穩定 ID（`R-001` 起連號，格式：條目行首 `- R-NNN 2026-...`）。**Append-only、不重用**——新條目一律編下一個未用的 R-NNN；既有條目的 ID 一旦編定不因排序或合併而改變或回收。
