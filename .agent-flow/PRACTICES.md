# 任務與背景資料

依 [OpenAI 最佳做法](https://learn.chatgpt.com/guides/best-practices) 整理；以下是本專案對兩種 harness 的應用。

- 派工寫清楚目標、相關背景、限制與完成條件。附必要的檔案與原文契約。
- 入口保留長期規則與可執行驗證指令。流程細節依 Router 選定的 skill 載入。
- 多步或有歧義的工作先建立計畫；單一工作在同一 run 完成，分支工作才隔離。
- 實作交付附測試證據與限制；審查依實際變更範圍進行。
- skill 各負責一種工作，寫明輸入、輸出與觸發條件；先用代表案例驗證。
- 外部工具須解決實際資料需求。流程穩定後才考慮排程。

模型值由專案政策設定。此指南不自動變更已指定的模型或權限。
