# RETRO

> 每條寫成可直接貼進 writer prompt 的**約束句式**（背景一句、約束一句），不寫敘事——retro 的消費方式是前置進 prompt 硬性約束區（eval-flow 循環 step 1），不是開工前通讀。
>
> 以下 `[seed]` 條目為跨專案通用約束庫（init.sh 部署，來源：實測 run 反覆出現的 🔴 類別）；本專案自己的教訓由 retro agent 往下累積。

- 2026-07-15［seed／資料外洩］外部 API 的原始回應體（含其錯誤訊息）曾直接流進使用者可見的 reason 欄位。**約束：對外輸出（log、錯誤訊息、reason／message 欄位）一律白名單挑欄位重組，不可直接轉發外部回應體或其片段。**
- 2026-07-15［seed／cache］cache-hit 分支曾照常打付費 API（cache 只省了解析、沒省呼叫）。**約束：有 cache 的付費／限流呼叫，必須以 mock 計數驗證「hit 時外部呼叫次數為 0、miss 時為 1」，不可只驗回傳值相等。**
- 2026-07-15［seed／rate-limit］迴圈內裸打外部付費／限流 API 造成限流與費用風險。**約束：迴圈呼叫外部 API 必須有節流／退避與呼叫上限，並在測試中以 mock 驗證上限生效。**
- 2026-07-15［seed／假測試］斷言藏在 if-guard 底下的測試，條件不成立時默默通過（散文教訓擋不住，同一 run 內重現）。**約束：測試斷言不可置於無 else 兜底的 if 之下；無斷言的測試視同未測。機械防線：`test_lint.py`（step 5 與 commit gate 會擋）。**
- 2026-07-15［seed／字串處理］`lstrip("www.")` 被當前綴移除使用，實為字元集合移除，白名單比對因此失效。**約束：去前綴用 `removeprefix`（或明確切片），不可用 `lstrip`／`strip`；網域／URL 白名單比對用解析後的結構化欄位，不可用字串修剪。**
- 2026-07-15［seed／介面］憑印象呼叫既有函式，參數名／型別／回傳結構連錯多次（每次都反證實作是對的，純浪費輪次）。**約束：呼叫跨 item／跨模組的既有函式前，先以 `inspect.signature` 或讀定義確認實際介面；多參數呼叫一律用關鍵字參數，避免位置錯位。**
